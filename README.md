## 1. Project Overview

This repository contains a lightweight **RRDB-Net (Residual-in-Residual Dense Block)** trained to restore degraded semiconductor inspection images suffering from three simultaneous degradations:

- **Speckle noise** (out-of-range pixel values)
- **Gaussian blur / additive noise**
- **2× spatial resolution reduction (super-resolution)**

The model accepts a noisy, low-resolution grayscale `.npy` file and outputs a clean, high-resolution `.npy` file at 2× scale.

**Key specs:**
- Architecture: RRDB-Net (12 blocks, 64 features, PixelShuffle upsampling)
- Parameters: ~2.8M
- Inference speed: ~2.07 ms/image on NVIDIA H100
- Input: `(1, H, W)` float32, values may exceed `[0, 1]`
- Output: `(1, 2H, 2W)` float32, clamped to `[0, 1]`

## 5. Evaluation / Inference (Standalone Script)

The `evaluate.py` script is the **primary file used by KLA's benchmarking team**. It requires **zero manual edits**.

### 5.1 Usage

```bash
python evaluate.py \\
    --input_dir /path/to/test/images \\
    --output_dir /path/to/save/restored \\
    --model_path ./checkpoints/best_model.pth
```

### 5.2 Example (Linux / Colab)

```bash
python evaluate.py \\
    --input_dir ./datasets/Test_NoisyLR/NoisyLR \\
    --output_dir ./outputs/restored \\
    --model_path ./checkpoints/best_model.pth
```

### 5.3 Example (Windows PowerShell)

```powershell
python evaluate.py `
    --input_dir ".\datasets\Test_NoisyLR\NoisyLR" `
    --output_dir ".\outputs\restored" `
    --model_path ".\checkpoints\best_model.pth"
```

### 5.4 What It Does

1. Loads all `*.npy` files from `--input_dir`
2. Runs inference on GPU if available, else CPU
3. Saves restored `*.npy` files to `--output_dir` (same filenames as input)
4. Prints per-image time and average throughput

### 5.5 Expected Output

```

Processing 400 images...
000000.npy | 2.10 ms
000001.npy | 2.05 ms
...
```

## 6. Training from Scratch

To reproduce the training process:

### 6.1 Prepare Data

Organize your paired training data as:

```
datasets/
└── train/
    └── train/
        ├── NoisyLR/          # Degraded images (low-res, noisy)
        │   ├── 000000.npy
        │   └── ...
        └── GT/               # Ground truth images (high-res, clean)
            ├── 000000.npy
            └── ...
```

### 6.2 Run Training

```bash
python train.py \\
    --train_degraded ./datasets/train/train/NoisyLR \\
    --train_gt ./datasets/train/train/GT \\
    --checkpoint_dir ./checkpoints \\
    --epochs 300 \\
    --batch_size 16 \\
    --lr 2e-4
```

**Notes:**
- On Windows, use `num_workers=0` (default in code).
- On Linux/Colab, `num_workers=4` is enabled automatically for speed.
- Mixed precision (AMP) activates automatically when CUDA is available.
- Best model is saved to `checkpoints/best_model.pth` based on validation PSNR.

### 6.3 Resume from Checkpoint

If training is interrupted, resume by loading the latest checkpoint in your training script or re-run with the same `--checkpoint_dir`.

Create side-by-side PNGs (Noisy | Restored | GT) for reports/PPTs:

```bash

    --degraded_dir ./datasets/Test_NoisyLR/NoisyLR \\
    --restored_dir ./outputs/restored \\
    --gt_dir ./path/to/test/ground_truth \\
    --output_dir ./evaluation_results
```

This produces:
- `evaluation_results/comparisons/*.png` — side-by-side images
- `evaluation_results/results.csv` — per-image PSNR/SSIM + mean scores
